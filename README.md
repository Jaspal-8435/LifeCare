# LifeCare

LifeCare is a MERN stack web application for online blood test booking and home sample collection. Users can explore available tests, schedule appointments, make secure payments, and download their reports. The platform also includes an admin dashboard for managing users, tests, and appointments.

## Features

- User registration and login with JWT
- Blood test booking
- Home sample collection scheduling
- Razorpay payment integration
- PDF report management
- Admin dashboard
- CRUD operations for users, tests, and appointments
- Responsive user interface

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- JWT
- REST API
- Razorpay

## Installation

```bash
git clone https://github.com/Jaspal-8435/LifeCare.git
cd LifeCare
```

Install dependencies

```bash
cd backend
npm install

cd ../frontend
npm install
```

Run the application

```bash
npm start
```
